# PaperCraft 0.4.0 preview

- Open `.fig` files as new, unsaved PaperCraft documents, or convert locally with `papercraft convert design.fig --output design.papercraft`. Import keeps supported first-page Frames, groups, rectangles, ellipses and plain text editable, including hierarchy, translation and sibling ordering. The source is not an automatic save destination; the editor refuses `.fig` saves.
- Conversion is best effort: images, vectors, instances, rotated/scaled layers, gradients, strokes, effects, richer typography, layout rules, variables, prototypes and additional pages are not converted. Warnings describe these limits. Synthetic fixtures and installed-app smoke checks pass; actual Figma exports remain unverified. See [Figma import](https://github.com/slyim/papercraft/blob/main/docs/fig-import.md).
- Includes the editable starter Frame, off-artboard workspace, bounded geometry-aware selection and navigation, and authored straight/Bézier Pen work added since the published 0.3.0 preview. Frame subtree moves preserve child offsets; Frame resize changes the container without scaling children. Pen supports anchor/handle editing and point modes.
- Clarifies MCP text alignment: choose `text_align` and text-box width explicitly; `update_layer` changes alignment while preserving geometry. Live history regressions cover left/center/right alignment. The Agent dock remains local notes/presets, not an embedded agent runner.
- Native files retain the lowest representable format. Canonical Bézier anchors use v4; older readers reject unsupported versions without changing the file. HTML/SVG exports remain artboard-bounded and reject shaders/ancestor clipping; PNG supports frame/region exports. No full Figma/Paper parity is claimed.

Download the matching installer or portable archive and verify it with `SHA256SUMS.txt`. Publication requires tests, native checks and packaging on all five targets, then checksum verification of all 12 payloads. macOS is ad-hoc signed and not notarized; Windows is unsigned. Native dialogs, physical input and Windows native interaction remain incompletely verified, so this remains an early preview.
