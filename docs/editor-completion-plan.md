## 1a contract (written before implementation)

### Coordinates, interaction and cancellation

- World units are existing document units, x right/y down. Every stored node x/y remains **absolute world geometry**, even with a parent. The legacy artboard remains the background rectangle and **default export region**, not a workspace clip or another frame collection. Existing top-level Frame nodes are screen containers.
- Author shapes, frames and text anywhere in the canvas viewport, including negative x/y. Existing finite position limits ±100,000 and dimensions 1–100,000 remain. GUI drag/click rounds/clamps through existing creation rules; MCP rejects out-of-range authored values. Parent/shader initialization must enter the same creation transaction, never modify the committed result afterward.
- 1a selection is explicitly **bounding-box selection** (including transparent shapes); accurate ellipse/triangle/path/stroke tests remain 1b/4. Hover/click/double-click share the same world hit lookup, respecting inherited hiding/locking and rectangular ancestor clipping. Marquee uses visible clipped bounds. No claim of glyph/pixel hit testing.
- Move/resize drafts live outside authoritative `editor.document`. Each release commits once through Editor; release coordinates are included. Escape or focus loss discards the draft/creation and restores marquee's prior selection, without document/history/revision/redo changes. A cancelled held pointer must not create or commit on its eventual release. Other keyboard document actions wait until gesture completion. Tab switch/clear must cancel a draft, not retain uncommitted geometry.
- Pan and pointer-anchored wheel/pinch zoom affect view only; disable navigation while a geometry gesture is active to avoid coordinate drift. Zoom range 0.001–4. Fit content (Shift+1), fit selection (Shift+2), fit artboard (Shift+0) and zoom menu recover distant work; empty content falls back to artboard, empty selection reports a recovery message. F remains Frame. Fit has a 64-point margin where zoom limits permit and a 2× ceiling. View state is tab-local and not saved.

### Agent and render contract

- Inspection reports coordinate space, artboard bounds, visible clipped content bounds and per-layer world bounds. Batch results include resulting created-layer bounds, content bounds and named reference IDs.
- Optional creation `ref` is a batch-local label (1–64 ASCII letters/digits/`_`/`-`), used later as `{"ref":"label"}` in matching ID fields/arrays. It resolves only earlier results, checks layer/token/directive kind, rejects duplicate/unknown/forward/mistyped refs, and never persists. A failed reference/operation/final validation leaves document, selection, revisions and both history stacks unchanged. Existing numeric IDs and token-name references remain accepted.
- `document_render` and PNG `document_export` accept exactly one of `region:{x,y,width,height}` or `frame_id`; omission preserves artboard output. Region positions/dimensions obey existing world limits, scale remains 0.1–8, and existing 16,384-side/64-Mi-pixel limits apply **before allocation/writing**. Frame crop uses that frame's world bounds and the entire visible composition in that crop, not an isolated subtree. Replies include exact world bounds and pixel dimensions. Canvas and PNG use the same painter and ancestor clips. Outside the artboard is transparent in region PNG, not the UI surround color.
- GUI selection-PNG export uses the same bounded renderer. Region HTML/SVG is explicitly rejected before writing; default HTML/SVG still export only the artboard. Unsupported shader/ancestor-clipping vector exports must reject with an actionable PNG alternative rather than silently dropping/approximating them. Existing text font/wrap limitations remain documented.
- Save never silently upgrades an opened file: headless MCP needs explicit `allow_upgrade:true` or a new path; live MCP retains GUI confirmation/new-path rules. Cross-document save/export destinations cannot overwrite another open source. Source reads/failed exports leave original bytes untouched.

### Compatibility and proof gate

No native file schema change. v1/v2/v3 release fixture read/save/reopen and unknown/default-field rejection tests; no migration or coordinate reinterpretation. Rollback: previous v0.3.0 opens these files unchanged (its canvas still hides off-artboard content); discard/regenerate derived region PNGs. v0.2.0 rollback is limited to its v3 typography subset; toolkit data cannot be losslessly downgraded.

Required checks: regression first for off-artboard creation/painting, isolated drafts/cancel/redo, fit/anchored zoom and live/headless bounded rendering; batch-local ref/failure/state tests; save/reopen and destination preservation; extend `verify_native` with offboard creation and cancellation, inspect actual captures/exports. Run `cargo fmt --check`, `cargo test --locked`, `cargo clippy --locked --all-targets -- -D warnings`. Record actual commands/results and unperformed checks below. Stop after 1a; no vector/hierarchy completion claim.

## Verification record

**Result: baseline reconciliation and bounded slice 1a implemented and verified; stop here.** No schema/version/dependency change, proprietary code/assets, release publication or installed-app replacement. Stage 1b and stages 2–9 remain open.

### Implementation and preservation

- `src/document.rs`: shared world/clipped bounds, bounding-box hit lookup and inherited selection locks; configured creation initializes parent/shader before validation/history. Legacy v1/v2 newer-key presence rejects even for null/default values. Saved v0.3.0 geometry/normalized vertices are preserved, with lowest-version writing.
- `src/app.rs`: world viewport creation/painting, tab-local fit/zoom/pan, separate move/resize draft documents and one release transaction. Escape/focus loss/clear discard drafts, restore marquee selection, consume eventual releases and preserve redo. Input cancellation runs in both visible UI and background logic; live mutation rejects even before drag threshold. Opening a tab cancels before storing the previous Editor.
- `src/{cli,mcp,render}.rs`: inspection bounds/capability limits, typed batch-local references, bounded region/frame PNG, transparent off-artboard background and resource checks. GUI selection-PNG uses that renderer. Failed operations/exports and protected destinations preserve bytes and state. Headless in-place upgrades reject first, then require explicit consent.
- Unsupported SVG relative/curve/multiple-contour input now rejects, rather than silently making polylines. This is an input-correctness fix, **not** authored Pen/curve completion. The rail labels the legacy entry Path preset. Agent-panel categories, local notes and presets no longer claim provider/ACP execution.

### Native-input investigation and remaining checks

Three archived v0.3.0 baseline text runs passed too. The raw diagnostic trace is ignored/private at `research/private/workspace-verification/input-interference.trace`; temporary instrumentation was removed and no physical input was filtered or fake focus forced. Successful text run logs remain at `/tmp/papercraft-native-text-repeat-{1,2,3,4}.log`.
